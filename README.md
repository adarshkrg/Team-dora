# ⚡ NEXUS PROTOCOL — Life RPG Engine (Team-dora)

> Transform real-life tasks and daily habits into an immersive, cyberpunk RPG progression engine with non-linear XP leveling, attribute matrices, streak chains, Black Market hardware economy, and native 8-bit retro sound synthesizers.

---

## 🌐 Live GitHub Pages Deployment

The application is configured for automated CI/CD deployment via GitHub Actions:
👉 **URL:** [https://adarshkrg.github.io/Team-dora/](https://adarshkrg.github.io/Team-dora/)

### ⚙️ Enabling GitHub Pages in this Repository

1. Open your repository on GitHub: [https://github.com/adarshkrg/Team-dora](https://github.com/adarshkrg/Team-dora)
2. Go to **Settings** > **Pages**
3. Under **Build and deployment** > **Source**, select **GitHub Actions**
4. The workflow in `.github/workflows/deploy.yml` will automatically build and publish the live site on every push to `main`!

## 🎮 Core RPG Features

- **Six Neural Pathway Attributes**:
  - ⚔️ **Strength** — Gym, workout, sports, physical fitness
  - 🧠 **Intellect** — Coding, learning, reading, research
  - 🎯 **Discipline** — Routines, habit consistency, focus blocks
  - 💚 **Vitality** — Recovery, sleep, hydration, meditation
  - ✨ **Charisma** — Public speaking, social, networking, team leadership
  - 🎨 **Creativity** — Design, music, writing, drawing, artistic projects

- **Dynamic Environment Backdrops**:
  - Switch between the 6 thematic environments with custom color palettes and ambiance.

- **Neural Core Skill Tree**:
  - Visual node-based tree showing your mastery and attribute level breakdown.

- **Black Market Hardware Shop & Inventory**:
  - Purchase neural implants, cybernetic augments, and boosters using earned Credits (₡).
  - Equip / detach items with instant attribute bonuses.

- **Audio Synthesizer Engine**:
  - Built-in retro 8-bit Web Audio API sound effects for quest completions, purchases, and level-ups with no external asset lag.

- **Instant Evaluation Demo Mode**:
  - One-click instant demo allows full gameplay evaluation immediately without requiring account creation.

